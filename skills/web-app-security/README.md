# Web Application Security Skill

This skill converts the supplied *Web Application Security* reference into an original, reusable workflow for authorized web application security assessment.

It is intended for:
- Web application reconnaissance
- API and attack-surface mapping
- Security architecture review
- Secure code review
- Authorized vulnerability validation
- Vulnerability triage and management
- Defensive recommendations
- Regression-test planning

The skill does not reproduce the source book. It synthesizes its structure and major concepts into operational instructions and checklists.

## Installation

Copy the `web-application-security` directory into the skills directory used by your agent, for example:

`.agents/skills/web-app-security/`

Then load/use the skill according to your agent's skill mechanism.
