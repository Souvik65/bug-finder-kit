# Web Application Recon Checklist

- [ ] Confirm authorization and scope.
- [ ] Identify domains and subdomains.
- [ ] Identify application entry points.
- [ ] Map HTTP methods and important request/response flows.
- [ ] Discover and classify API endpoints.
- [ ] Identify authentication mechanisms and privilege tiers.
- [ ] Identify client-side technologies.
- [ ] Identify server-side technologies where observable.
- [ ] Identify databases/storage technologies where observable.
- [ ] Inventory third-party integrations and dependency versions.
- [ ] Identify trust boundaries and sensitive data flows.
- [ ] Identify inconsistent security controls.
- [ ] Record hypotheses before active validation.
